# Security

This repository is the lite validator (babylon-node-lite), a derivative of the Radix Babylon node.

- **Vulnerabilities in the lite validator** (anything below `docs/lite-validator/`, the `lite`
  packages and the changes listed in [NOTICE](NOTICE)): please report them privately to
  Michael@Radixscan.io, not in a public issue. Of particular interest: anything that could let a
  lite validator write to, lock or damage the database of the validator it reads, or sign twice.
- **Vulnerabilities in the Babylon node itself:** please report them to Radix as described in
  the upstream repository, https://github.com/radixdlt/babylon-node.

There is no bug bounty. Reports are handled on a best-effort basis.
